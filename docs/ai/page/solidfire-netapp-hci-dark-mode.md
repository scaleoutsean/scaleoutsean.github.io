# Dark Mode for NetApp HCI and SolidFire

DIY dark mode for SolidFire and NetApp HCI

### NetApp HCI, SolidFire, eSDS Web UI

![SolidFire Web UI in Dark Mode](/assets/images/solidfire-netapp-hci-dark-mode.png)

The above image is SolidFire v12.0 viewed from Firefox and Dark Reader.

There's another open source browser extension called Dark Mode. 

Both are available for Firefox, Chrome, and Edge.

### Element Plug-in for VMware vCenter (aka VCP)

It too works well (evaluated with Dark Mode, for example.)

If you use Dark Theme in vCenter and want VCP in dark mode, you need to switch back to Light Theme in vCenter, and then enable dark mode in your browser extension.

### NetApp HCC

NetApp HCC (Hybrid Cloud Control) also looks nice with dark mode extensions.

### Make sure you get the extension you want

Check the home page of the extension, reviews, etc. 

Knock-off extensions may attempt to steal your credentials.
